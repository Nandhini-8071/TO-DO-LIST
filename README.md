🚀 Cloud Ready Todo
A modern single-page Task Management Web Application designed to efficiently manage daily tasks with features like CRUD operations, filtering, priorities, and due date tracking.


📌 Problem Statement
Managing tasks manually often leads to missed deadlines, poor prioritization, and lack of proper tracking. This project provides a simple and structured solution to organize, monitor, and manage tasks effectively.


✨ Features
* 📝 Add, edit, delete tasks (CRUD)
* 📅 Set due dates
* 🚦 Priority levels (Low, Medium, High)
* 🔍 Filter by status & priority
* 📊 Insights (Total, Pending, Completed)
* 🧹 Clear completed tasks
* 💾 Auto-save using local storage
* 🎨 Clean & responsive UI


🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Storage: Browser Local Storage


⚡ How It Works
User enters task details → saves task → data stored in local storage → tasks displayed → filters applied → tasks updated or deleted → insights updated dynamically.
